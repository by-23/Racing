ШЕЙДЕР СИЛОВОГО ПОЛЯ - ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ
==================================================

Описание:
Шейдер "ForceField" создает эффект полупрозрачного силового поля с голубым свечением,
эффектом Френеля, пульсацией и анимированным шумом, как показано на изображении.

Файлы:
- ForceField.shader - основной шейдер
- ForceField.mat - материал с настройками по умолчанию
- ForceFieldSphere.prefab - готовый prefab сферы с эффектом
- ForceFieldController.cs - скрипт для управления параметрами

Как использовать:
1. Перетащите prefab "ForceFieldSphere" в сцену
2. Настройте параметры в компоненте ForceFieldController
3. Или создайте свой объект с материалом ForceField

Параметры шейдера:
- Color: основной цвет силового поля (по умолчанию: голубой)
- Alpha: прозрачность (0-1)
- Fresnel Power: сила эффекта Френеля (свечение по краям)
- Fresnel Scale: масштаб эффекта Френеля
- Rim Power: сила rim lighting эффекта
- Rim Intensity: интенсивность rim lighting
- Pulse Speed: скорость пульсации
- Pulse Intensity: интенсивность пульсации
- Noise Scale: масштаб шума
- Noise Speed: скорость анимации шума
- Distortion: искажение UV координат

Параметры скрипта ForceFieldController:
- Animate Color: включить анимацию цвета
- Secondary Color: второй цвет для анимации
- Color Animation Speed: скорость анимации цвета

Методы скрипта:
- SetColor(Color) - изменить цвет
- SetAlpha(float) - изменить прозрачность
- SetPulseSpeed(float) - изменить скорость пульсации
- SetIntensity(float) - изменить общую интенсивность
- ActivateForceField() - включить силовое поле
- DeactivateForceField() - выключить силовое поле
- ResetToDefault() - сбросить к настройкам по умолчанию

Советы:
- Для лучшего эффекта используйте на сферических объектах
- Разместите объект на темном фоне для лучшей видимости
- Экспериментируйте с параметрами Fresnel для разных эффектов
- Используйте Pulse Speed для создания энергетических эффектов

Технические детали:
- Шейдер использует blend mode SrcAlpha OneMinusSrcAlpha
- Рендерится в очереди Transparent
- Отключено написание в Z-buffer для правильной прозрачности
- Отключен culling для видимости с обеих сторон

Для создания вариаций:
1. Скопируйте материал ForceField
2. Настройте параметры под ваши нужды
3. Сохраните как новый материал
